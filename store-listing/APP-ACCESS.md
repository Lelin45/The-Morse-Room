# App access for Google Play review

Learn, Practice, Codes, sound settings and themes work without signing in. Chat requires an account.

In Play Console, select the option indicating that some functionality is restricted. Use the review email and password you supplied in its credential fields.

Paste this into the reviewer instructions field:

> Learn, Practice and Codes do not require sign-in. Open Chat, then tap Review access. Enter the email and password supplied in the App access fields. No Google sign-in, verification code or two-factor step is needed for this review account. The account opens isolated test conversations with review_bot, a test friend request and a test group. Send text or Morse code, then use Show text and Listen. You can test reporting, blocking, unblocking through the account menu and account deletion. If you delete the test account, sign in through Review access again to recreate it. Ordinary users sign in with Google only for Chat.

The account deletion URL is:

https://learnmorse.lelinadhikari.com.np/delete-account.html

More developer setup details are in [the repository's Play Console guide](https://github.com/Lelin45/The-Morse-Room/blob/main/docs/PLAY_CONSOLE.md).
